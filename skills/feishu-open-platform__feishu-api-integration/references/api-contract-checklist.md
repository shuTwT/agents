# 飞书 API 契约检查清单

在提交代码前，逐项记录证据或明确标记为待确认：

## API 选择

- [ ] 业务对象和操作动词明确。
- [ ] 使用的 API 版本、HTTP 方法和路径来自官方文档。
- [ ] 请求体、查询参数和响应字段与文档一致。
- [ ] 是否需要分页、排序、过滤或批量接口已确认。

## 身份与权限

- [ ] 调用主体是应用、租户还是用户。
- [ ] token 类型、获取方式、过期时间和刷新方式已确认。
- [ ] 所需权限名称来自官方文档，并区分应用权限和用户授权。
- [ ] 多租户或用户授权场景没有把凭证写入代码或日志。

## 可靠性

- [ ] 超时、连接失败和 5xx 有有限重试。
- [ ] 4xx 按参数、权限、资源不存在等类别处理，不盲目重试。
- [ ] 写操作有幂等策略，避免重试造成重复副作用。
- [ ] 批量接口处理部分失败和分页游标。
- [ ] 错误日志不包含 token、Authorization header 或敏感业务数据。

## 事件与回调

- [ ] URL 验证和事件签名流程已确认。
- [ ] 处理器能快速响应并把耗时工作异步化。
- [ ] 事件 ID 或业务键用于去重。
- [ ] 重复投递、乱序和失败重试有处理策略。
